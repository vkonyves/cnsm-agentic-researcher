# v0.4.1 Finalist Resolution

This additive milestone resolves study-design tournament ties before the
research state advances to `DESIGN_SELECTED`.

It adds:

- finalist-specific scientific criteria;
- configurable finalist-resolution weights;
- deterministic finalist scoring;
- preservation of the runner-up as a planned follow-up study;
- a dedicated finalist-resolution CLI;
- generation of the selected study, experiment DAG, claim ledger, state, and
  generation manifest only after finalist resolution.

For the current NetOps programme, the deterministic resolution selects:

- C2: Structured reasoning mitigation

and preserves:

- C4: Task-complexity moderation

as the planned follow-up study.
