# v0.6 Autonomous Discovery Bootstrap

This milestone begins the scientifically autonomous cycle.

It removes candidate-specific decisions and adds:

- literature-query planning;
- OpenAlex and Crossref discovery;
- DOI/title deduplication;
- evidence synthesis with record IDs;
- autonomous candidate generation;
- autonomous criticism;
- evidence-grounded selection;
- provenance-preserving outputs.

It deliberately stops at `AUTONOMOUS_DESIGN_SELECTED`. It does not freeze or execute a final study.
